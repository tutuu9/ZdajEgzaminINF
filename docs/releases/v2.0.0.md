# v2.0.0 — Piętnaście kursów i przygotowanie do egzaminu

## English

The largest update since the first release. The number of complete INF.03 courses grows from 8 to **15**. A handbook, a full exam simulation and a guide to the exam day are added, and the public server now has twice the capacity. Version 1.6.0 was prepared but never published; its manual deployment workflow is part of this release.

- **Seven new courses from published CKE papers:** Moje zadania (INF.03-02-25.06-SG), Systemy liczbowe (INF.03-06-25.01-SG), Panele podłogowe (INF.03-02-25.01-SG), and four courses from June 2026: Atlas drzew (INF.03-11-26.06-SG), Salon rowerowy (INF.03-12-26.06-SG), Kółko i krzyżyk (INF.03-07-26.06-SG) and Karta produktu (INF.03-03-26.06-SG). Each course has 48–61 steps, and every step points to its paper page.
- **Handbook (Podręcznik):** separate books for HTML, CSS, JavaScript, SQL and PHP. In a course, the Pomoc tab links each step to the matching chapter.
- **Exam preparation:** the **Jak wygląda egzamin** page walks through the practical part and marks CKE rules separately from the details of one paper. A timed Egzamin attempt shows a stage plan and a checklist before hand-in. After hand-in, the report lists the files the paper requires and supports self-review. A study plan, theory mistake review and practice from exam reports are also added.
- **Papers:** the Arkusze list shows the newest sessions first. It filters by session and by papers without PHP, and search also matches the printed paper code.
- **Graphics check:** for 14 papers in the catalogue, the project automatically checks the prepared images: file name, format, size, transparency and GIF frames.
- **SQL and PHP:** in Nauka, Baza i PHP opens a practice view similar to phpMyAdmin. It compares the learner's query with the example from the current step without running SQL on the server. Trusted local installations add an interactive PHP and SQL workspace with MariaDB. Public code execution stays disabled.
- **FAQ:** 16 new entries on XAMPP and MariaDB (installation, phpMyAdmin imports, common Apache, PHP and MariaDB errors) with screenshots. The FAQ now has 51 answers.
- **Learning workspace:** Ctrl+Enter (⌘+Enter) checks the current course step. Check results are described in plain language. On phones, all project views fit without a hidden tab, and the start choice appears before the requirements.
- **Deployment and server:** the public site is updated by one manual **Deploy public site** run in GitHub Actions. The workflow requires passed Checks, a pinned SSH host key, a fresh verified database backup and an unchanged server Compose file, and it never rolls back migrations. The VPS now has 2 vCPU, 4 GB RAM and 120 GB NVMe. PostgreSQL is limited to 768 MiB (`shared_buffers` 192 MB), and the API and initialization to 1 GiB each. An update requires 1280 MiB `MemAvailable`.

All 15 courses, 25 theory examples and 51 FAQ answers are source-backed. No examination score is invented. Browser-local projects and backups remain compatible. Before deploying, update the server copies of `compose.site.yaml` and `deploy.sh` and recreate PostgreSQL after a fresh backup, as described in `docs/site-deployment.md`.

Release gates are the complete quality, API, checker/isolation and Playwright suites, followed by a public deployment and acceptance on the site. Observed results are recorded in the published GitHub Release after verification.

## Polski

Największa aktualizacja od pierwszego wydania. Liczba pełnych kursów INF.03 rośnie z 8 do **15**. Dochodzą podręcznik, pełna symulacja egzaminu i przewodnik po dniu egzaminu, a publiczny serwer ma dwa razy więcej zasobów. Wersja 1.6.0 była przygotowana, ale nie została opublikowana; jej ręczne wdrażanie wchodzi w skład tego wydania.

- **Siedem nowych kursów z opublikowanych arkuszy CKE:** Moje zadania (INF.03-02-25.06-SG), Systemy liczbowe (INF.03-06-25.01-SG), Panele podłogowe (INF.03-02-25.01-SG) oraz cztery kursy z czerwca 2026: Atlas drzew (INF.03-11-26.06-SG), Salon rowerowy (INF.03-12-26.06-SG), Kółko i krzyżyk (INF.03-07-26.06-SG) i Karta produktu (INF.03-03-26.06-SG). Każdy kurs ma od 48 do 61 kroków, a każdy krok wskazuje stronę arkusza.
- **Podręcznik:** osobne książki o HTML, CSS, JavaScript, SQL i PHP. W kursie zakładka Pomoc kieruje z kroku do pasującego rozdziału.
- **Przygotowanie do egzaminu:** strona **Jak wygląda egzamin** opisuje część praktyczną i oddziela zasady CKE od szczegółów jednego arkusza. W egzaminie z limitem czasu widać plan etapów i listę kontrolną przed oddaniem. Po oddaniu raport wymienia pliki wymagane przez arkusz i pomaga w samodzielnej ocenie. Dochodzą też plan nauki, przegląd błędów z teorii i ćwiczenia na podstawie raportów z egzaminu.
- **Arkusze:** lista pokazuje najpierw najnowsze sesje. Można filtrować według sesji i arkuszy bez PHP, a wyszukiwarka rozpoznaje też kod arkusza.
- **Sprawdzanie grafiki:** dla 14 arkuszy z katalogu projekt automatycznie sprawdza przygotowane obrazy: nazwę pliku, format, wymiary, przezroczystość i klatki GIF.
- **SQL i PHP:** w trybie Nauka zakładka Baza i PHP otwiera widok ćwiczeniowy podobny do phpMyAdmin. Porównuje zapytanie ucznia z przykładem z bieżącego kroku, bez uruchamiania SQL na serwerze. Zaufane instalacje lokalne otrzymują interaktywne środowisko PHP i SQL z MariaDB. Publiczne uruchamianie kodu pozostaje wyłączone.
- **FAQ:** 16 nowych odpowiedzi o XAMPP i MariaDB (instalacja, import w phpMyAdmin, typowe błędy Apache, PHP i MariaDB) ze zrzutami ekranu. FAQ ma teraz 51 odpowiedzi.
- **Obszar nauki:** Ctrl+Enter (⌘+Enter) sprawdza bieżący krok kursu. Wyniki kontroli są opisane zwykłym językiem. Na telefonie wszystkie widoki projektu mieszczą się bez ukrytej zakładki, a wybór sposobu pracy jest widoczny przed wymaganiami.
- **Wdrażanie i serwer:** publiczny serwis aktualizuje się jednym ręcznym uruchomieniem **Deploy public site** w GitHub Actions. Workflow wymaga zaliczonych Checks, sprawdzonego klucza hosta SSH, nowej sprawdzonej kopii bazy i niezmienionego pliku Compose na serwerze. Nigdy nie cofa migracji. VPS ma teraz 2 vCPU, 4 GB RAM i 120 GB NVMe. PostgreSQL ma limit 768 MiB (`shared_buffers` 192 MB), a API i inicjalizacja po 1 GiB. Aktualizacja wymaga 1280 MiB `MemAvailable`.

Wszystkie 15 kursów, 25 przykładów teoretycznych i 51 odpowiedzi FAQ ma źródła. System nie wymyśla oceny egzaminacyjnej. Lokalne projekty i kopie postępu pozostają zgodne. Przed wdrożeniem zaktualizuj na serwerze kopie `compose.site.yaml` i `deploy.sh` oraz po nowej kopii bazy utwórz ponownie kontener PostgreSQL, jak opisano w `docs/site-deployment.md`.

Warunki publikacji obejmują pełne testy jakości, API, sprawdzania/izolacji i Playwright, a następnie publiczne wdrożenie i odbiór na stronie. Wyniki zostaną zapisane w GitHub Release po weryfikacji.
