# v1.4.0 — Pisz szybciej

## English

Learn HTML abbreviations while building your own examination project. **Pisz szybciej** adds contextual guidance to **149 activities across all eight INF.03 courses**, at every preparation level in unfinished **Nauka** projects.

- **Use a shortcut where it fits.** Each relevant step shows an abbreviation, a short Polish explanation, its insertion context and expandable **Zobacz HTML** output. For `link:css`, the tip explains the actual `style.css` default and the filename required by the current task. Learners make the correction themselves; the shortcut does not create a CSS file.
- **Understand the notation.** **Skróty HTML** offers seven reference topics: starter shortcuts, `>` and `+`, text `{}`, climb-up `^` and `^^`, repetition `*` and numbering `$`, classes/IDs/attributes, and grouping `()`. An incremental walkthrough explains `header>h1{Tytuł}^main>p{Treść}^footer`.
- **Keep control of your code.** **Kopiuj skrót** copies only to the clipboard. Reading examples does not replace project files, and correct existing HTML can stay as written. Emmet is optional; normal step checks accept manually written markup. The existing bounded expansion engine and one-step Undo are retained, including HTML regions of PHP files.

The reference supports keyboard navigation, mobile panels and both themes. CSS property abbreviations are outside this update. Trening, Egzamin and completed work do not show the new teaching aid. Published guides, API contracts, database schema and backup formats are unchanged; existing work requires no migration. See [Emmet learning details](https://github.com/tutuu9/ZdajEgzaminINF/blob/v1.4.0/docs/emmet-learning.md).

Validation passed in [feature CI](https://github.com/tutuu9/ZdajEgzaminINF/actions/runs/42414130286): **384 unit tests, 33 API tests, 71 checker/isolation tests and all 95 Playwright scenarios**, with no browser retries. The browser suite includes all eight courses, filename correction, Undo, reload/import, clipboard failure and mobile/theme checks.

## Polski

Poznaj skróty HTML podczas budowania własnego projektu egzaminacyjnego. **Pisz szybciej** dodaje wskazówki do **149 czynności we wszystkich ośmiu kursach INF.03**, na każdym poziomie przygotowania w niezakończonych projektach **Nauka**.

- **Użyj skrótu we właściwym miejscu.** Przy odpowiednim kroku zobaczysz skrót, krótkie objaśnienie, miejsce wpisania i rozwijany wynik **Zobacz HTML**. Dla `link:css` wskazówka wyjaśnia domyślne `style.css` oraz nazwę wymaganą w bieżącym zadaniu. Zmianę wykonujesz samodzielnie; skrót nie tworzy pliku CSS.
- **Zrozum zapis.** **Skróty HTML** zawierają siedem tematów: podstawowe skróty, `>` i `+`, tekst `{}`, powrót `^` i `^^`, powtarzanie `*` i numerowanie `$`, klasy/identyfikatory/atrybuty oraz grupowanie `()`. Osobny rozbiór pokazuje krok po kroku `header>h1{Tytuł}^main>p{Treść}^footer`.
- **Zachowaj kontrolę nad kodem.** **Kopiuj skrót** kopiuje wyłącznie do schowka. Czytanie przykładów nie zastępuje plików projektu, a poprawny HTML możesz pozostawić bez zmian. Emmet jest opcjonalny; zwykłe kontrole kroku przyjmują kod napisany ręcznie. Zachowano dotychczasowe ograniczenia rozwijania i cofanie jednym poleceniem, także we fragmentach HTML plików PHP.

Ściąga obsługuje klawiaturę, panele mobilne i oba motywy. Skróty właściwości CSS nie wchodzą w zakres aktualizacji. Trening, Egzamin i zakończone prace nie pokazują nowej pomocy. Opublikowane kursy, kontrakty API, schemat bazy i formaty kopii postępu pozostają bez zmian; istniejące prace nie wymagają migracji. Więcej: [nauka Emmet](https://github.com/tutuu9/ZdajEgzaminINF/blob/v1.4.0/docs/emmet-learning.md).

W [CI funkcji](https://github.com/tutuu9/ZdajEgzaminINF/actions/runs/42414130286) przeszły **384 testy jednostkowe, 33 testy API, 71 testów sprawdzania i izolacji oraz wszystkie 95 scenariuszy Playwright**, bez ponawiania testów przeglądarkowych. Scenariusze obejmują osiem kursów, poprawienie nazwy pliku, cofanie, odświeżenie/import, odmowę dostępu do schowka i widoki mobilne w obu motywach.
