# v1.2.0 — Pokaż na stronie

## English

Explore the page you are building and find the HTML and CSS behind it. **Pokaż na stronie** is available in unfinished **Nauka** projects across all eight INF.03 courses, at every learning level. [Try the Chat course](https://zdajegzamin.sbs/praktyka/inf03-02-24-06-sg?tryb=nauka&widok=nauka)

- **Select a page element and find its code.** Choose **Zbadaj stronę**, then click a heading, menu or image in the preview. The editor opens your HTML file, selects the opening tag and receives keyboard focus. CSS declaration links take you to the styles in your own files.
- **Understand what you wrote.** A compact card explains common tags and CSS properties in Polish. **Reguły pasujące do elementu** lists matching rules separately from **Wartości w podglądzie**, the values calculated by the browser. A matching rule is not presented as the sole cause of a result.
- **See sizes and spacing.** Enable **Pokaż odstępy** to explore content, padding, border and margin. Complex layouts use numerical values and an explanation instead of an inaccurate overlay. HTML mixed with PHP opens the source file with an explanation when an exact selection is unavailable; PHP is not executed.
- **Use the keyboard or your phone.** An element list supports keyboard selection; Escape ends inspection and returns focus to its button. On phones, selection opens **Kod**, with **Wróć do podglądu** to return. Light and dark themes are supported.

Inspection uses static HTML/CSS with learner JavaScript disabled. **Uruchom JS** exits inspection and returns to the existing isolated JavaScript preview. The inspector does not change files, Undo history or completion results, and does not award a CKE score. Existing projects, API contracts and backup formats remain compatible; no database migration is needed.

Validation passed: 294 unit tests, 33 API tests, 71 checker/isolation tests and the full 66-test Playwright suite in CI. All 18 inspector scenarios were verified on the public site: 17 passed on the first run; one timed out waiting for a guest session before inspection began and passed in a targeted rerun.

## Polski

Zbadaj stronę, którą tworzysz, i znajdź odpowiadający jej kod HTML i CSS. **Pokaż na stronie** działa w niezakończonych projektach **Nauka** we wszystkich ośmiu kursach INF.03, na każdym poziomie nauki. [Wypróbuj kurs Chat](https://zdajegzamin.sbs/praktyka/inf03-02-24-06-sg?tryb=nauka&widok=nauka)

- **Wybierz element strony i znajdź jego kod.** Kliknij **Zbadaj stronę**, a następnie nagłówek, menu lub obraz w podglądzie. Edytor otworzy Twój plik HTML, zaznaczy znacznik otwierający i przejmie fokus klawiatury. Odnośniki do deklaracji CSS prowadzą do stylów w Twoich plikach.
- **Zrozum napisany kod.** Niewielka karta objaśnia po polsku podstawowe znaczniki i właściwości CSS. **Reguły pasujące do elementu** są oddzielone od **Wartości w podglądzie**, czyli wartości obliczonych przez przeglądarkę. Pasująca reguła nie jest przedstawiana jako jedyna przyczyna wyniku.
- **Sprawdź rozmiary i odstępy.** Włącz **Pokaż odstępy**, aby obejrzeć zawartość, dopełnienie, obramowanie i margines. Przy złożonym układzie zobaczysz wartości liczbowe i wyjaśnienie zamiast niedokładnej nakładki. Jeśli HTML przeplata się z PHP i nie można wskazać dokładnego fragmentu, otworzy się plik z wyjaśnieniem ograniczenia. PHP nie jest wykonywany.
- **Korzystaj z klawiatury lub telefonu.** Lista elementów umożliwia wybór klawiaturą; Escape kończy badanie i przywraca fokus przyciskowi. Na telefonie wybór otwiera panel **Kod**, a **Wróć do podglądu** pozwala wrócić do strony. Obsługiwane są jasny i ciemny motyw.

Badanie korzysta ze statycznego HTML/CSS z wyłączonym JavaScriptem ucznia. **Uruchom JS** kończy badanie i wraca do dotychczasowego, izolowanego podglądu JavaScript. Inspektor nie zmienia plików, historii cofania ani wyników ukończenia i nie przyznaje oceny CKE. Dotychczasowe projekty, kontrakty API i format kopii zapasowych pozostają zgodne; migracja bazy danych nie jest potrzebna.

Weryfikacja zakończyła się pomyślnie: 294 testy jednostkowe, 33 testy API, 71 testów sprawdzania i izolacji oraz pełny zestaw 66 testów Playwright w CI. Na publicznej stronie sprawdzono wszystkie 18 scenariuszy inspektora: 17 przeszło za pierwszym razem, a jeden przekroczył czas oczekiwania na sesję gościa przed rozpoczęciem badania i przeszedł po osobnym ponowieniu.
