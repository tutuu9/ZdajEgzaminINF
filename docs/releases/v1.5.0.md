# v1.5.0 — Asystent AI i usprawnienia nauki

## English

The practical workspace gains a conversational DeepSeek assistant that reads the reviewed original paper, the current course activity, project text files and findings from local checks. It explains mistakes with file, line and paper references, while the learner keeps control of the code. Sending requires consent; unfinished examinations keep AI unavailable. Conversations stay in the current tab.

- The public deployment can opt into AI without enabling server code execution. The provider key belongs only to the API; initialization remains closed by default. Existing budget reservations, uncertain-call handling and the $2 initial total cap are retained. Former default limits move to 48,000 input tokens and 30 requests per session daily; custom limits are preserved.
- Nauka has focused Krok, Pomoc and Eksperyment panels, a horizontal file strip and editor/preview layouts for laptop, Full HD and QHD screens. Editor tools, the JavaScript console and script restart improve work with the learner's own page.
- Project ZIP import handles enclosing folders, unsupported entries and Windows-1250 text. Preview scripts can read the original image addresses. Typography, browser titles and interface states are clearer.
- Theory learning offers immediate per-question explanations, preserves answers from two tabs and supports handing in from the last question. Training keeps explanations until submission.
- Trusted local infrastructure adds bounded SQL/PHP runs and clearer worker diagnostics. Public execution still requires independently verified Linux/gVisor isolation and remains disabled in this deployment.

All eight published courses, 25 theory examples and 35 FAQ answers remain source-backed. No examination score is invented. Browser-local projects and backups retain compatibility. Apply the checked-in migrations before starting the updated API; code rollback preserves database data and AI spending records.

Release gates are the complete quality, API, checker/isolation and Playwright suites, optional-AI Compose checks, a restore-tested database backup and public browser/API acceptance. Observed results are recorded in the published GitHub Release after verification.

## Polski

W obszarze praktycznym pojawia się asystent DeepSeek, który czyta sprawdzony oryginalny arkusz, bieżącą czynność kursu, pliki tekstowe projektu i wyniki lokalnych kontroli. Wyjaśnia błędy, wskazując plik, wiersz i stronę arkusza, a uczeń sam zmienia kod. Wysłanie wymaga zgody; AI pozostaje niedostępne w niezakończonym egzaminie. Rozmowa zostaje tylko w bieżącej karcie.

- Publiczny serwis może korzystać z AI bez uruchamiania kodu na serwerze. Klucz otrzymuje tylko API; inicjalizacja domyślnie wyłącza funkcję. Zachowano rezerwacje budżetu, obsługę niepewnych rozliczeń i początkowy limit 2 USD łącznie. Dawne limity domyślne rosną do 48 000 tokenów wejściowych i 30 zapytań na sesję dziennie; własne ustawienia pozostają bez zmian.
- Nauka ma panele Krok, Pomoc i Eksperyment, poziomy pasek plików oraz układ edytora i podglądu dopasowany do laptopów, Full HD i QHD. Narzędzia edytora, konsola JavaScript i ponowne uruchamianie skryptów ułatwiają pracę z własną stroną.
- Import ZIP obsługuje folder otaczający pliki, pomijanie nieobsługiwanych elementów i tekst Windows-1250. Skrypty podglądu odczytują oryginalne adresy obrazów. Poprawiono czytelność tekstu, tytuły kart i komunikaty interfejsu.
- Nauka teorii wyjaśnia każde pytanie od razu, zachowuje odpowiedzi z dwóch kart i pozwala oddać serię z ostatniego pytania. W treningu wyjaśnienia pojawiają się po oddaniu.
- Zaufana infrastruktura lokalna otrzymuje ograniczone uruchamianie SQL/PHP i dokładniejszą diagnostykę procesu sprawdzającego. Publiczne uruchamianie kodu nadal wymaga osobnej weryfikacji Linux/gVisor i pozostaje wyłączone w tym wdrożeniu.

Osiem opublikowanych kursów, 25 przykładów teoretycznych i 35 odpowiedzi FAQ zachowuje źródła. System nie wymyśla oceny egzaminacyjnej. Lokalne projekty i kopie postępu pozostają zgodne. Przed uruchomieniem nowego API zastosuj migracje z repozytorium; cofnięcie kodu zachowuje dane bazy i historię wydatków AI.

Warunki publikacji obejmują pełne testy jakości, API, sprawdzania/izolacji i Playwright, kontrole Compose z opcjonalnym AI, kopię bazy ze sprawdzonym odtworzeniem oraz odbiór przeglądarkowy/API na publicznej stronie. Wyniki zostaną zapisane w GitHub Release po weryfikacji.
