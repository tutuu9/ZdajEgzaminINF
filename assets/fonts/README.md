# PDF fonts

The API embeds Source Sans 3 Regular and Semibold in original task PDFs so Polish characters render without relying on fonts installed on the learner's device.

The OTF files come from Adobe's official [Source Sans release directory](https://github.com/adobe-fonts/source-sans/tree/release/OTF), retrieved on 2 November 2026. The accompanying `LICENSE.md` is preserved from that repository and contains the SIL Open Font License 1.1. Browser font files and their licenses remain in the web application's public assets.
