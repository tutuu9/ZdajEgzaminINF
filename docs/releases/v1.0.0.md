# Release 1 — Liquid Glass and cumulative learning

## English

The first release preserves the redesigned learning workspace and three cumulative CKE INF.03 courses: Kursy komputerowe, Wędkowanie and Baza Smoków.

- Liquid Glass navigation, readable lesson surfaces and responsive lesson, code and preview panels.
- One growing project across 175 learning actions: changing steps never replaces the learner's files.
- Per-file editor history, restored workspace position, explicit save errors and protection against conflicting tabs and late reports.
- Versioned guides, retained legacy notes and version 2 local backups with version 1 import support.
- Structural HTML/CSS checks and isolated educational JavaScript scenarios. PHP, SQL, graphics and unsupported requirements remain clearly marked for manual review; educational results are not official CKE scores.
- Polish learning content, 25 official theory examples, original PDF access and local progress without learner accounts.

Release gating requires the complete GitHub Actions quality, PostgreSQL, sandbox and Playwright jobs to pass before the immutable tag is published. Public Linux/gVisor deployment and VPS sizing remain unverified.

## Polski

Pierwsze wydanie zachowuje odnowioną pracownię oraz trzy stopniowe kursy CKE INF.03: Kursy komputerowe, Wędkowanie i Baza Smoków.

- Nawigacja Liquid Glass, czytelne materiały oraz responsywne panele lekcji, kodu i podglądu.
- Jeden rozwijany projekt w 175 czynnościach: zmiana kroku nigdy nie zastępuje plików ucznia.
- Historia edycji osobna dla każdego pliku, przywracanie miejsca pracy, widoczne błędy zapisu oraz ochrona przed konfliktem kart i spóźnionymi raportami.
- Wersjonowane przewodniki, zachowane stare notatki i lokalne kopie w wersji 2 z importem wersji 1.
- Strukturalne sprawdzanie HTML/CSS i izolowane scenariusze JavaScript. PHP, SQL, grafika i nieobsługiwane wymagania mają jawne sprawdzanie ręczne; wyniki nauki nie są oceną CKE.
- Polskie materiały, 25 oficjalnych przykładów teoretycznych, oryginalne PDF-y i lokalny postęp bez kont uczniów.

Publikacja niezmiennego tagu wymaga przejścia pełnych kontroli GitHub Actions: jakości, PostgreSQL, izolowanego wykonawcy i Playwright. Publiczne wdrożenie Linux/gVisor oraz wymagania konkretnego VPS pozostają niezweryfikowane.

## Upgrade and rollback / Aktualizacja i powrót

Apply checked-in PostgreSQL migrations before starting the updated API. Keep browser backups and database backups before changing versions. A release tag restores source code only: it neither deletes learner progress nor automatically reverses PostgreSQL migrations or IndexedDB formats. Prefer a reviewed revert that retains data compatibility. Never use volume removal as a code rollback.

Przed uruchomieniem nowego API zastosuj migracje PostgreSQL z repozytorium. Przed zmianą wersji zachowaj kopie przeglądarki i bazy. Tag przywraca tylko kod: nie usuwa postępu i nie cofa automatycznie migracji ani formatu IndexedDB. Preferuj sprawdzony revert zgodny z aktualnymi danymi. Nie usuwaj wolumenów w celu cofnięcia kodu.
