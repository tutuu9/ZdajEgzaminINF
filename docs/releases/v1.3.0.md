# v1.3.0 — Zmień i zrozum

## English

Connect a small HTML/CSS edit to the page it produces. **Zmień i zrozum** is available at every learning level in unfinished **Nauka** projects across all eight INF.03 courses. [Try the Chat course](https://zdajegzamin.sbs/praktyka/inf03-02-24-06-sg?tryb=nauka&widok=nauka)

- **Understand the next change.** Short Polish explanations and diagrams describe the current HTML/CSS concept. **Pokaż miejsce zmiany** opens the relevant source in your own project. Optional prediction questions help you think about the result without blocking progress or awarding points.
- **Compare your own work.** **Porównaj przed i po** switches between the page saved at the start of the step and your current page. **Co zmieniłem?** shows added and removed source lines. Switching views preserves your code and Undo history; examples are not inserted automatically.
- **Return safely.** **Przywróć punkt sprzed kroku** first preserves your newer work as a separate project in **Moje prace**, then restores the checkpoint. Storage failures, conflicting tabs and edits made during restoration are handled without silently replacing newer code. Oversized projects can retry checkpoint creation after their size is reduced.
- **Keep learning on different screens.** Keyboard controls, light and dark themes and phone panels are supported. The comparison heading remains visible below mobile navigation, and background cursor saves no longer swallow comparison clicks.

Checkpoints and predictions stay in the browser and travel with progress backups. History holds up to eight checkpoints and 20 MiB in total. Existing projects capture their current files instead of resetting to starter code; earlier version-1 and version-2 backups remain supported.

Comparison uses static HTML/CSS: learner JavaScript, PHP and outside network requests are disabled. It does not provide a model solution or a CKE score, and requires no AI calls. Published guides and server API contracts are unchanged; no database migration is needed. See [comparison and restoration details](https://github.com/tutuu9/ZdajEgzaminINF/blob/v1.3.0/docs/change-understand.md).

Validation passed: 344 unit tests, 33 API tests, 71 checker/isolation tests and the full 86-test Playwright suite in [feature CI](https://github.com/tutuu9/ZdajEgzaminINF/actions/runs/42365706113). All 20 feature scenarios also passed on the public site with zero retries.

## Polski

Połącz małą zmianę HTML/CSS z wyglądem własnej strony. **Zmień i zrozum** działa na każdym poziomie nauki w niezakończonych projektach **Nauka** we wszystkich ośmiu kursach INF.03. [Wypróbuj kurs Chat](https://zdajegzamin.sbs/praktyka/inf03-02-24-06-sg?tryb=nauka&widok=nauka)

- **Zrozum następną zmianę.** Krótkie objaśnienia i schematy po polsku wyjaśniają zagadnienie HTML/CSS z bieżącego kroku. **Pokaż miejsce zmiany** otwiera odpowiedni fragment Twojego projektu. Opcjonalne pytania pomagają przewidzieć wynik bez blokowania postępu i przyznawania punktów.
- **Porównaj własną pracę.** **Porównaj przed i po** przełącza stronę zapisaną na początku kroku oraz stronę bieżącą. **Co zmieniłem?** pokazuje dodane i usunięte wiersze kodu. Przełączanie widoków zachowuje kod i historię cofania; przykłady nie są wstawiane automatycznie.
- **Bezpiecznie wróć do zapisu.** **Przywróć punkt sprzed kroku** najpierw zachowuje nowszą pracę jako oddzielny projekt w **Moje prace**, a następnie przywraca punkt. Błędy zapisu, konflikty kart i zmiany wprowadzone podczas przywracania nie nadpisują po cichu nowszego kodu. Po zmniejszeniu zbyt dużego projektu można ponowić zapis punktu.
- **Ucz się na różnych ekranach.** Dostępne są sterowanie klawiaturą, jasny i ciemny motyw oraz panele na telefonie. Nagłówek porównania pozostaje widoczny pod mobilną nawigacją, a zapis pozycji kursora w tle nie przerywa już kliknięcia przycisku porównania.

Punkty i przewidywania pozostają w przeglądarce i trafiają do kopii postępu. Historia mieści do ośmiu punktów i łącznie 20 MiB. W istniejących projektach zapisywane są bieżące pliki, bez powrotu do początkowego szkieletu; wcześniejsze kopie w wersjach 1 i 2 nadal są obsługiwane.

Porównanie korzysta ze statycznego HTML/CSS: JavaScript ucznia, PHP i zewnętrzne połączenia sieciowe są wyłączone. Nie udostępnia wzorcowego rozwiązania ani oceny CKE i nie wymaga zapytań do AI. Opublikowane kursy i kontrakty API serwera pozostają bez zmian; migracja bazy danych nie jest potrzebna. Więcej: [porównanie i przywracanie](https://github.com/tutuu9/ZdajEgzaminINF/blob/v1.3.0/docs/change-understand.md).

Weryfikacja zakończyła się pomyślnie: 344 testy jednostkowe, 33 testy API, 71 testów sprawdzania i izolacji oraz pełny zestaw 86 testów Playwright w [CI funkcji](https://github.com/tutuu9/ZdajEgzaminINF/actions/runs/42365706113). Wszystkie 20 scenariuszy funkcji przeszło również na publicznej stronie bez ponawiania.
